# kb-electron-skeleton
App Electron minima de base de conocimiento. `npm install && npm start`; tests con `npm test`.

## Exportar conversacion
El boton "Exportar" (canal IPC `conv:export`, `window.kb.convExport()`) guarda la conversacion actual como Markdown en `data/exports/conversacion-YYYYMMDD-HHMMSS.md` (UTC; nunca sobrescribe, anade `-2`, `-3`...) y muestra el archivo creado. La escritura es atomica (temporal + renombrado; sin hard links usa un `.lock` exclusivo y nunca escribe en el nombre final). Falla con `EINVAL` si no hay turnos o el año de `now` esta fuera de 0000-9999. Registra `conv.export` con `{ file, turns, from, to }` (`from`/`to`: turnos efectivamente exportados).

### Exportar un rango de turnos
`conversationToMarkdown` y `exportConversation` aceptan `opts.fromTurn` y `opts.toTurn` (enteros, base 1, inclusive). Solo `fromTurn` -> hasta el ultimo turno; solo `toTurn` -> desde el 1; `undefined`/`null` cuentan como ausentes. Los turnos conservan su numero original (`## 2. ...`) y, solo con rango, la cabecera lleva el rango: `_Exportada: <ISO> · 2 turnos (2–3 de 5)_`. Sin rango la cabecera no cambia. Un rango invalido (no entero, `< 1`, mayor que el total, `fromTurn > toTurn`) lanza `Error` con `code === 'EINVAL'` y no crea ningun archivo; `turns` es el numero de turnos exportados. El canal `conv:export` acepta un argumento opcional `{ fromTurn, toTurn }` (`window.kb.convExport(range)`); un rango invalido hace fallar el canal con ese error. El argumento debe ser `undefined`, `null` o un objeto; cualquier otro valor (cadena, numero, booleano, array) hace fallar el canal con `EINVAL` y no crea ningun archivo (`{}` cuenta como sin rango). Un rango pleno `1..N` cuenta como rango aplicado (se decide por la presencia de `fromTurn`/`toTurn`, no por su valor): la cabecera lleva `(1–N de N)`. El boton "Exportar" sigue exportando todo.
