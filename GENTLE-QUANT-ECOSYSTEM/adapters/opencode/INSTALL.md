# OpenCode Adapter — Persistent Installation

Deployment guide for installing canonical Gentle general and Quant specialists
into an OpenCode runtime.

This is deployment, not authority. Canonical authority remains:

- `agents/<specialist>/ROLE.md`
- `agents/<specialist>/SUBAGENT.md`
- `agents/SUBAGENT-CONTRACT-SPEC.md`
- `agents/TASK-PACKET-CONTRACT-SPEC.md`
- `agents/HANDOFF-CONTRACT-SPEC.md`

The installer only projects those sources into runtime configuration.

---

## What it installs

Into a user-owned OpenCode config layer (`~/.config/opencode/opencode.jsonc`):

- eight agent entries: `ui-ux-engineer`, `software-engineer`, `data-engineer`,
  `data-scientist`, `quant-data-engineer`, `quant-researcher`,
  `quant-developer`, and `quant-validator` (`mode: subagent`, `tools.task: false`);
- `agent.gentle-orchestrator.permission.task` allows those specialists.

Plus generated prompt files under:

`~/.config/opencode/gentle-specialists/prompts/`

The managed `opencode.json` layer (owned by `gentle-ai/sdd`) is never modified.

---

## Prerequisites

- `opencode` available on `PATH`;
- canonical sources present in this repository;
- a writable user-owned config layer.

---

## Install

```bash
cd /path/to/GENTLE-QUANT-ECOSYSTEM

# preview (no writes)
python3 adapters/opencode/install_registration.py --dry-run

# install (creates a timestamped backup next to the config)
python3 adapters/opencode/install_registration.py
```

---

## Validate

```bash
# agent resolves with the canonical generated prompt
opencode debug agent quant-researcher

# higher-priority layer must deep-merge with the managed layer:
#   task."*" = deny, sdd-* allow preserved, quant-* allow added
opencode debug config | sed -n '/"gentle-orchestrator"/,/}/p'

# runtime discovery
opencode agent list
```

---

## Rollback

```bash
# remove the managed agents, task allows, and prompts dir
python3 adapters/opencode/install_registration.py --uninstall

# or restore the pre-install backup
cp ~/.config/opencode/opencode.jsonc.bak-<timestamp> ~/.config/opencode/opencode.jsonc
```

---

## Determinism

The prompt files are generated by
`adapters/opencode/generate_registration.py` from canonical inputs. Repeated
generation from the same canonical revision is byte-identical
(`adapters/opencode/validate_registration.py`). The installer is idempotent:
re-running it with no canonical change makes no effective change.

---

## Notes

- The installer never writes inside the managed `gentle-ai/sdd` layer.
- It preserves unrelated config keys; a timestamped backup is always created.
- Registration does not authorize project work. Authoritative work still
  requires a READY Task Packet.
