# Gentle Quant Ecosystem

Canonical source for Gentle's controlled quantitative capability and global specialist-routing extensions.

## Authority

Gentle-AI is the primary orchestration harness.

This repository contains the portable extensions that govern quantitative-development workflows independently of any individual coding agent.

## Structure

- governance/ — global governance and policies
- skills/ — canonical reusable Gentle-compatible skills
- agents/ — runtime-independent general and Quant specialist role contracts
- templates/ — project governance templates
- tools/ — synchronization and enforcement tooling

Agent-specific installations such as OpenCode or Pi are deployment targets, not sources of truth.

Global routing is defined in `orchestration/GLOBAL-TASK-ROUTING.md`: work nature selects the specialist; project domain supplies context and protected boundaries.
